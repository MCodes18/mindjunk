# Add a capture

Drop a PNG, JPG, JPEG, WebP or AVIF image here or in a year subfolder, for example:
2026/2026-09-26-a-photo-title.png

New files appear automatically, without editing JavaScript.
The title comes from the filename (hyphens/underscores become spaces).
The date comes from a YYYY-MM-DD filename prefix. Otherwise the year comes from the folder name.
Files without either go into Undated.

Tape, doodles and rotation are automatic and stable.
The original three photographs keep their original captions and metadata.
Optional custom captions/place/rotation can be added to the metadata map in src/data/captures.js using the path relative to this folder as the key.

Rebuild and redeploy to update a published site.
